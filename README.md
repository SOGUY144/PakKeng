# [ชื่อเกม] — เว็บต้นแบบเกมฝึกพูด (เดโม)

เครื่องมือฝึกเสริมที่บ้าน ภายใต้คำแนะนำของนักแก้ไขการพูด
ต้นแบบนี้ยังไม่ได้ตรวจสอบเทียบกับ Nasometer ใช้ดูแนวโน้มจากการฝึกเท่านั้น ไม่ใช้วินิจฉัย

ค่าทั้งหมดในเดโมมาจาก **สัญญาณจำลอง** (MockSignalSource) — ยังไม่ได้ต่อ ESP32 จริง

เว็บเดโมที่ deploy แล้ว (รุ่น 3D): https://nasal-trainer-web.vercel.app — วิธี deploy ใหม่ดู `HANDOFF.md`

## เริ่มใช้งาน
```bash
npm install
npm run dev
```
เปิด
- ฝั่งเด็ก: http://localhost:5173/#/home
- แดชบอร์ดนักแก้ไขการพูด: http://localhost:5173/#/dashboard

## ตรวจงาน
```bash
npm run typecheck   # tsc strict
npm test            # vitest (logic เกม, ข้อมูล, กฎแจ้งเตือน, validation)
npm run lint        # oxlint
npm run build       # สร้างไฟล์ใน dist/
```

## 8 หน้าจอ (hash route)
`#/home` · `#/calibrate` · `#/runner` · `#/gate` · `#/result` · `#/balloon` · `#/frog` · `#/dashboard`

## เครื่องมือเดโม (อยู่ใต้หน้าเกม / ด้านขวาบนจอกว้าง)
- แถบเลื่อน “ค่าออกปาก (จำลอง)” 0–100% (ออกจมูก = 100 − ออกปาก)
- เสียงพูด: ไม่มีเสียง / มีเสียง / เป็นช่วง ๆ และปุ่ม “กดค้างเพื่อพูด” (หรือกด Space ค้าง)
- ตัวเลือกทดสอบเพิ่ม: ค่อย ๆ เปลี่ยน, แกว่งใกล้เกณฑ์, ตัด/ต่อการเชื่อมต่อ, **ภาพฉากเกม** (อัตโนมัติ / 3D สูง / 3D ประหยัด / 2D + ตัวนับ fps),
  **ภาพเคลื่อนไหว** (ตามเครื่อง / ลดลง / เต็ม), รีเซ็ต

## ฉาก 3D
ฉากเกมทั้ง 3 เกมและด่านประตูเป็น 3D (three.js + React Three Fiber) โหลดเป็น chunk แยกเมื่อเข้าเกม;
ถ้าเบราว์เซอร์ไม่มี WebGL หรือฉาก 3D หลุด จะแสดงภาพ 2D เดิมพร้อมคำอธิบายและปุ่มลองใหม่ — เล่นและนับผลได้เหมือนเดิม
โมเดลทั้งหมดสร้างด้วยโค้ดในโปรเจกต์ (ไม่มี asset ภายนอก) — ดู `ASSETS.md`

เอกสารประกอบ: `PROJECT_BRIEF.md`, `DECISIONS.md`, `PROGRESS.md`, `TODO.md`, `HANDOFF.md`, `NEXT_PROMPT.txt`, `ASSETS.md`
ภาพหน้าจอจากเบราว์เซอร์จริง: `docs/screenshots/` (01–09 รุ่น 2D = โหมดสำรอง, 10–21 ฉาก 3D)
