# FUN_GAMES_DESIGN — สัญญาการออกแบบรอบ “เกมสนุกขึ้น” (10–11 พ.ย. 2569)

ที่มา: งานวิจัยสั้นเรื่องเกม Roblox ที่มีคนเล่นมาก (Grow a Garden, Adopt Me!, Dress To Impress, Brookhaven, Tower of Hell, Steal a Brainrot)
และสิ่งที่เด็กชอบ — ใช้เป็น **สมมติฐาน** ไม่ใช่หลักฐานว่าเด็กกลุ่มนี้จะชอบ ต้องลองกับเด็กจริง (ดู “แผนลองเล่น” ท้ายไฟล์)
หลักที่ใช้ทุกข้อ (`.claude/skills/cleft-speech-game`, `references/evidence-th.md`):
- การพูดคือท่าหลักของเกม (Habgood & Ainsworth 2011: ทักษะเป็นกลไกเกม → เรียนได้มากกว่าและเลือกเล่นนานกว่า)
- รางวัลโตจาก **คำที่พูดตอนสัญญาณใช้ได้** เท่านั้น (ไม่ใช่เวลา การแตะ หรือเสียงตัวอย่าง) · ไม่มีกล่องสุ่ม เงิน โฆษณา streak ลงโทษ อันดับเทียบเด็ก
- ไม่ติดป้ายเพศกับเกม · แรงเตะ/คะแนนไม่ขึ้นกับความดัง · ห้าม “ยิ่งเสียงจมูกต่ำยิ่งชนะ”
- รอบที่เล่นด้วยเสียงจำลอง (โหมดสาธิต) ติดป้ายและแยกกองรางวัลจากรอบที่ใช้อุปกรณ์จริง
- บันทึกรอบด้วย id คงที่ต่อรอบ: บันทึกซ้ำ/รีเฟรช/เปิดผลซ้ำไม่ทำให้รางวัลเพิ่ม

## 1. ⚽ ยิงจุดโทษ (`#/kick`)
| เรื่อง | สัญญา |
|---|---|
| เป้าหมายเด็ก | ยิงให้ครบ 5 ลูก ได้ถ้วย |
| ทางเลือก | เลือกทีมที่จะเตะด้วย (ทีมเต่า / ปู / หมา / นก) → เปลี่ยนผู้รักษาประตู สีทีม กองเชียร์ ชื่อในผลรอบ |
| การกระทำ | ฟังคำ → พูด: เริ่มพูดแล้วนักเตะวิ่งเข้าหาลูกทันที · พูดจบคำและสัญญาณใช้ได้ → เตะ |
| ผลที่เห็น | ลูกลอยตามทางของลูกนั้น (5 แบบ เรียงตายตัว ไม่สุ่ม) ผู้รักษาประตูพุ่งผิดทางแบบตลก ตาข่ายป่อง กองเชียร์กระโดด → ลูกถัดไป |
| ไม่ลงโทษ | คำที่ใช้ได้ = ประตูทุกลูก · สัญญาณใช้ไม่ได้ = “ขอลองใหม่” นักเตะหยุดตรงนั้น ไม่ถอยหลัง · ข้ามลูกได้ |
| จบ/พัก/ลองใหม่ | ปุ่มพักมุมซ้าย (หยุดฟัง ลูกที่ลอยอยู่ลงต่อหลังพัก) · ลองใหม่ · ข้ามลูก · จบรอบดูสรุป |
| ผู้ดูแล | เกณฑ์ออกปากของผู้เชี่ยวชาญบันทึกในหน้าผู้ดูแลเท่านั้น ไม่ใช้ในฉาก · จำนวนคำที่ใช้ได้เข้า “คำที่พูดวันนี้” |
| โหลด/ผิดพลาด | 3D โหลดแยก chunk มีข้อความรอ · WebGL ใช้ไม่ได้ → ฉาก 2D เล่นครบ · อุปกรณ์หลุด → ฉากหยุด ไม่นับ |
| จอ | มือถือ: ฉาก + แถบคำด้านล่าง ปุ่มหลักในระยะนิ้วโป้ง · คอม: ฉากกว้าง + แถบลูก 1–5 ด้านข้าง |
| 3D | มุมมองแบบถ่ายทอดสดจากด้านหลังนักเตะ · นักเตะ = ตัวละครของเด็ก · ผู้รักษาประตู = เพื่อนสัตว์ของทีม · ลดการเคลื่อนไหว = ไม่ขยับกล้อง แกว่งน้อยลง แต่ลูกยังลอย |
| หลักฐานรับงาน | เทสต์ `src/logic/kick.test.ts` · เล่นครบ 5 ลูกในเบราว์เซอร์ 390×844 และ 1440×900 · 2D · ลดการเคลื่อนไหว · หน้าผลแสดงประตู |

## 2. 🏝 เกาะของฉัน (`#/island`): ตัวละคร ชุด สัตว์เลี้ยง สวน
| เรื่อง | สัญญา |
|---|---|
| เป้าหมายเด็ก | เห็นของที่ได้จากการพูด เลือกเอง และอยากกลับมาพรุ่งนี้ |
| ตัวละคร | เลือกได้ทันที 4 แบบ (กระต่าย ลูกหมา ไดโน แมวเหมียว) ไม่ต้องปลดล็อก ใช้ในทุกฉากที่มีตัวละครหลัก |
| ชุด | ของเดิม (หมวก รองเท้า ผ้าพันคอ มงกุฎ) ปลดล็อกด้วยดาวเหมือนเดิม · ของใหม่ (เสื้อบอล ผ้าคลุมฮีโร่ ฮู้ดไดโน ชุดเจ้าหญิง) ปลดล็อกด้วยจำนวนคำที่พูด แสดง “อีก N คำ” · ใส่ได้ช่องละชิ้น |
| สัตว์เลี้ยง | ครั้งแรกเลือกลูกหมาหรือลูกแมวได้เลย (ไม่ต้องรอ) · จากนั้นเลือกไข่ 1 ใบ พูดครบ 12 คำ (นับจากตอนเลือกไข่) → แตะฟัก · รู้ล่วงหน้าว่าไข่ไหนได้ตัวไหน · เลือกตัวที่จะพาไปเล่นด้วย |
| สวน | 3 แปลง เลือกเมล็ดเอง · โตตามคำที่พูดหลังปลูก (3 / 8 / 18 คำ) · วันที่ปลูกโตได้ถึงขั้น “กำลังโต” · พร้อมเก็บได้ตั้งแต่วันถัดไป · ไม่มีเหี่ยว ไม่มีตาย |
| ผู้ดูแล | เห็น “คำที่พูดวันนี้” แยกโหมดสาธิต/อุปกรณ์ · ปุ่มสาธิต “ข้ามไปวันพรุ่งนี้” ใช้ทดสอบสวนเท่านั้น (ติดป้ายสาธิต) |
| จอ | มือถือ: ตัวละคร + สัตว์ด้านบน แท็บ ตัวละคร/ชุด · สัตว์เลี้ยง · สวน · คอม: ฉากซ้าย แผงเลือกขวา |
| หลักฐานรับงาน | เทสต์ `src/data/rewards.test.ts` (นับคำ ไข่ สวน ชุด แยกโหมด ไม่ซ้ำ) · เล่นรอบหนึ่งแล้วเห็นไข่/ต้นไม้ขยับในเกาะ |

## เกณฑ์รับงานล่าสุดจากผู้ใช้ (ผ่านผู้คุมงาน 00:50): 3D เป็นภาพหลัก
- ทุกมินิเกมและพื้นที่หลักใช้ฉาก 3D/WebGL ที่เล่นได้จริงเป็นภาพหลัก — 2D เป็นทางสำรองเมื่อ WebGL ใช้ไม่ได้ และต้องเล่นจบได้
- ลดการเคลื่อนไหว = ยังเป็น 3D แต่ลดกล้อง/แอนิเมชัน · เกมเดิม 4 เกมคง 3D เดิม (ตรวจ regression)
- ฟุตบอล: สนามมุมมองบุคคลที่สาม นักเตะวิ่ง→เตะ ลูกลอย ผู้รักษาประตูพุ่ง ตาข่าย/กองเชียร์ตอบสนอง (สถานะจาก KickMatch)
- เกาะของฉัน: ฉาก 3D (`IslandWorld`) ตัวละครตามชนิด+ชุดที่เลือก สัตว์ที่พาไปด้วย ไข่ (รอยแตกตามความคืบหน้า ฟักเมื่อแตะ) แปลงผัก
  (ระยะโตตามความคืบหน้า โผล่ตอนโต เก็บแล้วหาย) — ปุ่ม HTML ด้านล่างเป็นตัวควบคุมที่เข้าถึงได้ ฉากเปลี่ยนตามข้อมูลรางวัลจริงเท่านั้น
- หลักฐานต่อส่วน: canvas WebGL ที่ 390×844 และ 1440×900 · ภาพก่อน/หลังการกระทำ · อ่านสถานะเกม (`window.__pakkengGame` เฉพาะ dev) คู่กับภาพ
- ห้ามเพิ่มมินิเกมใหม่จนฟุตบอลและเกาะ 3D ผ่านเกณฑ์นี้

## 3. แผนลองเล่นกับเด็กไทย 3–5 คน (ยังไม่ได้ทำ — ต้องมีผู้ปกครองและนักแก้ไขการพูดอยู่ด้วย)
- ให้เด็กเลือกเกมเอง เล่นราว 10 นาที ผู้ใหญ่ไม่บอกทางล่วงหน้า
- จด: เวลาถึงคำแรก จำนวนคำที่ใช้ได้ต่อนาที เกมที่เลือกเล่นซ้ำ จุดที่ต้องช่วย เหตุที่หยุด
- ถามสั้น ๆ: “อยากเล่นอันไหนอีก” “ชอบตัวไหน” — ไม่ถามแบบชี้นำ ไม่บันทึกเสียงเด็ก
