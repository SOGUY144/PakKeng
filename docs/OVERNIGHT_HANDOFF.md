### 2) รถไฟส่งของ 3D (เฟส 38) — vertical slice เดียว เล่นได้จบ
**design contract สั้น**
- **เลือกของก่อนเริ่ม**: “แตงโม → ส่งให้เต่าที่ชายหาด” หรือ “ดอกไม้ → ส่งให้นกที่ต้นไม้ใหญ่” — การ์ดเป็นภาพเรนเดอร์จากโมเดลเดียวกับฉาก (รถไฟพร้อมของที่เลือก ผู้รับที่สถานี ตัวละครของเด็กในห้องคนขับ)
  + หน้าผู้รับข้างคำ “ส่งให้…” · ผู้รับอยู่ในช่องภาพของแถบคำตลอดรอบ และอยู่บนสุดของรายการสถานี · สองทางเป็นทางแยกกลับซ้ายขวา **ระยะเท่ากัน** (เทสต์) ต่างแค่ของ ผู้รับ และทางแยก
- **4 ช่วง** (สถานีต้นทาง → 3 สถานี → สถานีผู้รับ) คำจากแผนเท่านั้น · ช่วงพูดที่ใช้ได้ 1 ครั้ง = รถวิ่ง 1 ช่วง (1.5 s) ความเร็ว ระยะ เวลาเท่ากันทุกครั้ง ไม่อ่านความดัง/ค่าจมูก/คำถูก
- **จังหวะ**: ฟังคำ (ไมค์ไม่ฟัง) → ลองพูด (ไอน้ำขึ้นจากปล่อง = ท่าเท่านั้น) → ปิดช่วงเสียง → รถออก (ไม่ฟัง) → เข้าสถานี 1.1 s (ไม่ฟัง: ธงขึ้น ประกาย เสียงชม แรงสั่น) → ฟังช่วงถัดไปหลังเฟรมเงียบ ·
  ช่วงสุดท้าย: คันสับรางหันไปทางผู้รับ · ถึงปลายทาง: ผู้รับดีใจ ของย้ายจากตู้ไปวางหน้าผู้รับ
- **ไม่เดิน ไม่ได้ดาว ไม่บันทึกสำเร็จ**: เงียบ / เสียงตัวอย่าง / พัก / ซ่อนหน้า / หลุด / ค้าง / ช่องไมค์หาย / ล้น / เบาเกิน — รถจอดรอที่เดิม พร้อมคำบอกสิ่งที่ทำต่อ · ไม่มีจับเวลา แพ้ รถถอย ของเสีย
- **ข้ามช่วง** = รถไหลไปถึงสถานีถัดไปเอง (1.8 s ช้ากว่า ไม่มีประกาย ไม่มีธง ไม่ได้ดาว ไม่นับการพูด) · ข้ามครบ 4 ช่วงก็ส่งของถึงผู้รับ (ผู้รับยังดีใจ) ผล “ส่ง…ถึง…แล้ว · รถไฟไหลไปเอง ·
  รอบหน้าลองพูดให้รถไฟวิ่งนะ” 0 ดาว · ไม่เขียนว่าพูดครบ
- **พัก/ซ่อนหน้ากลางทาง**: เวลาวิ่ง/เข้าสถานี/ไหลเป็นเวลาเชิงตรรกะ (ผลรวม dt ที่ตัด 100 ms/เฟรม) → ค้างจริง ไม่วาร์ป · ล้อหมุนตามระยะทาง (ไม่ใช่เวลา)
- **3D**: มุมกล้อง isometric จากด้านหลังเยื้องขวาบน กล้องไม่หมุนไม่ซูม เลื่อนตามรถตามแนวราง (ช่วงสุดท้ายเลื่อนไปทางผู้รับ) · หัวรถจักร + ตู้ + ของที่เลือก + ตัวละครเด็กในห้องคนขับ ·

- **จังหวะ**: ฟังคำ (ไมค์ไม่ฟัง) → ลองพูด (ตัวละครย่อตัว = ท่าเท่านั้น) → ปิดช่วงเสียง → กระโดด (ไม่ฟัง) → ลงแท่น 1.1 s (ไม่ฟัง: ยุบตัว ของประดับชั้นนั้นสว่าง ประกาย เสียงชม แรงสั่น)
  → ฟังคำชั้นถัดไปหลังเฟรมเงียบ (re-arm เดิมของ CallGame) · แตะ “ชั้นต่อไป” ตัดช่วงลงแท่นได้ (ชั้นนั้นนับแล้ว)
- **ไม่กระโดด ไม่ได้ดาว ไม่บันทึกสำเร็จ** เมื่อ เงียบ / เสียงตัวอย่าง / พัก / หลุด / ค้าง / ช่องไมค์หาย / ล้น / เบาเกิน — อยู่แท่นเดิม ข้อความบอกสิ่งที่ทำต่อ ไม่มีตก ถอย แท่นหาย จับเวลา หรือแพ้
- **ข้ามชั้น** = ลิฟต์เมฆก้อนเล็กพาขึ้น (1.2 s ไม่ฟัง) ไม่นับเป็นการพูด ไม่ได้ดาว ของประดับชั้นนั้นไม่สว่าง (สีดินปั้นเทา — ไม่ใช่โทษ) · ข้ามครบ 5 ชั้นถึงยอดและจบได้ ผลเขียนว่า
  “ถึงยอดหอคอยแล้ว · ลิฟต์เมฆพาขึ้นมา · รอบหน้าลองพูดแล้วกระโดดเองนะ” ดาว 0 · **ไม่เขียนว่าพูดครบ** (`towerHeadline` + เทสต์)
- **พัก / ซ่อนหน้า กลางกระโดด**: เวลาท่ากระโดด/ลงแท่น/ลิฟต์เป็นเวลาเชิงตรรกะ = ผลรวม dt ของเฟรมที่เกมทำงานจริง (ตัดที่ 100 ms/เฟรม; เฟรมแรกหลังพัก dt = 0) ไม่ใช้นาฬิกาผนัง
  → ค้างอยู่กลางอากาศจริง กลับมาหลัง 10 s ไปต่อจากจุดเดิม ไม่วาร์ปลงแท่น ไม่จบรอบเอง (ต่างจาก `RouteRun`/`KickMatch` ที่ใช้ `now - t0`)
